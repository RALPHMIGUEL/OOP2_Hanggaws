Syndicate - Terminal Heist Game

Build & Run

From the workspace root (where `src` lives):

```bash
javac -d out src/com/syndicate/*.java
java -cp out com.syndicate.SyndicateApp
```

Save files are written to `save.txt` in the workspace root.

Gameplay

- Use the menu to view hideout, shop, save/load, and run missions.
- Recruit crew and buy items in the shop.
- Run missions by selecting team members and items.

Enjoy!
